# Kontribusi ke AegisVault

Terima kasih telah tertarik untuk berkontribusi pada AegisVault! Kami menyambut baik segala jenis kontribusi, baik itu perbaikan bug, penambahan fitur, atau peningkatan dokumentasi.

## Cara Berkontribusi
1. Fork repositori ini.
2. Buat branch baru untuk fitur Anda (`git checkout -b fitur/FiturHebat`).
3. Commit perubahan Anda (`git commit -m 'Menambahkan fitur hebat'`).
4. Push ke branch tersebut (`git push origin fitur/FiturHebat`).
5. Buka Pull Request.

## Standar Kode
- Gunakan standar PEP 8 untuk kode Python.
- Pastikan untuk menambahkan komentar pada logika yang kompleks.
- Sertakan pengujian jika memungkinkan.

## Melaporkan Bug
Jika Anda menemukan bug, silakan buka *Issue* baru dengan deskripsi lengkap tentang masalah tersebut dan langkah-langkah untuk mereproduksinya.
